## Homebrew 安装（发布后补充）

```sh
brew tap JackCaow/zapcode-releases https://github.com/JackCaow/zapcode-releases
# 支持 Tap Trust 的 Homebrew：检查 Formula 后，仅信任这一项
brew trust --formula jackcaow/zapcode-releases/zap-vm-preview
brew install jackcaow/zapcode-releases/zap-vm-preview
zap-vm-preview
```

不支持 `brew trust` 的旧版可省略该行。命令不覆盖已有 `zap` / `zapdev`。
本机已通过安装、`brew test` 和 Homebrew 启动入口的真实 VM 挂载/写保护复测。
仅新增分发 Formula 与说明，压缩包内容及 SHA256 未更改。Homebrew 不代替 Apple 公证。

## 重要限制

1. 仅 Apple Silicon，未验证 Intel Mac。使用 ad-hoc 签名，**尚未 Developer ID 签名、公证**；Gatekeeper 可能阻止浏览器下载的包。请勿全局关闭系统安全保护。
2. Agent 在 Host，工作区进程工具在 VM，不是整个 Agent 或所有工具的 VM 隔离。
3. 现有 Guest Resident Runner 未更新，不能视为 Resident 解耦部署完成。
4. Guest 错误仍可能显示为 `unavailable` / 69；全仓测试并非全绿。
5. 这是预览版，现支持上面的 Homebrew Tap；npm 和旧版 `install.sh` 尚未接入。

如希望直接双击即用，请等待正式签名、公证版本。
