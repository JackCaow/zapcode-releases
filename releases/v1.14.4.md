# zapAgent 1.14.4 — macOS Apple Silicon

Fixes since 1.14.3, found while using it for real work.

- **Esc interrupts a running agent again** even when follow-ups are queued. Before, a leftover queue entry made Esc open `/queue` instead, so the agent could only be stopped with Ctrl+C. `Ctrl+Q` and `/queue` still open the queue at any time.
- **Provider connections created from the directory keep their preset.** DeepSeek connections now get the preset request parameters and `/effort` values, Google/Moonshot/Alibaba/Zhipu connections saved by older versions regain their model metadata, and a gateway on another host never inherits a preset.
- **`/effort` rejects values the provider does not support** (for DeepSeek: `high`, `max`) instead of saving a typo and sending it on every request. Providers with no declared values still accept anything.
- **A failed `/compact` no longer blocks the next one** with "Compact already in progress".
- **Queued messages with pasted screenshots no longer stall the TUI.** The pending-message journal stores the image path instead of its base64 bytes, and the bytes are reloaded from the file after a restart.
- Anthropic-compatible endpoints that expose `/models` with Bearer auth are retried once with it after a 401.

Worth knowing:
- DeepSeek connections created from the provider directory in earlier 1.14.x builds get the default `thinking: enabled` on upgrade, which can add latency and tokens. `/effort off` does not turn it off; remove `thinking` from the connection's `extraRequestParams` in the config file to opt out.
- After an interruption the queue stays paused until the failed entry is retried or removed in `/queue`; new input waits behind it without a notice (tracked in #54).

Install or update with Homebrew:

```sh
brew tap JackCaow/zapcode-releases https://github.com/JackCaow/zapcode-releases
brew update
brew upgrade jackcaow/zapcode-releases/zapagent
```

For first installation, replace `upgrade` with `install`. The commands `zapAgent`, `zap` and `zapcode` are supported. Stop active tasks and the VM daemon before upgrading.

Commands run under the host OS sandbox by default; the bundled VM is opt-in (`ZAPCODE_EXECUTION=vm`). This distribution covers macOS Apple Silicon only. No model, API key or user data is included. Command-line archives are not stapled; first-use ticket verification needs connectivity. Keep Gatekeeper and quarantine enabled.
