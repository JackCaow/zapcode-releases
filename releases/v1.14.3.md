# zapAgent 1.14.3 — macOS Apple Silicon

Commands now run on your Mac under the OS sandbox by default instead of being
fixed inside the VM, so local toolchains (bun, npm, Xcode, ...), network access
and opening a page in your browser work again.

- Default: host sandbox. Writes are limited to the workspace; `.git` and `.zapcode` stay read-only; network is open.
- A command blocked by the sandbox can be retried outside it (`dangerouslyDisableSandbox`). Every call needs your explicit approval, saved allow rules never cover it, and deny rules win. Set `allowUnsandboxedCommands: false` to remove the option.
- The bundled VM is opt-in: `ZAPCODE_EXECUTION=vm` or `"executionBackend": "vm"`.

Verification: 2775 tests passed, typecheck passed; two independent reviews; real tmux
runs of bun, curl, npm install, a blocked write outside the workspace, and an approved
sandbox escape that opened a page in the browser. Hosted package jobs cannot run the VM
(no hardware virtualization), so package activation is verified on a native Mac.
