# zapAgent 1.14.2 — macOS Apple Silicon

Provider setup now continues directly into model selection instead of closing after saving an API key.

Homebrew uses the supplementary `-sparse.tar.gz` archive to preserve VM disk
holes during extraction (about 770 MiB allocated). Its file contents and signed
binaries match the original package checksums and notarized ZIP exactly.

- Save a new connection, discover its models, select one and finish.
- Choose later with Esc: the connection remains saved and an existing active model is preserved.
- Use m in the connection list to open models for that connection.
- Retry discovery or enter a model ID manually when discovery is unavailable.
- Editing a connection preserves its existing model preferences.

Install or update with Homebrew:

```sh
brew tap JackCaow/zapcode-releases https://github.com/JackCaow/zapcode-releases
brew update
brew upgrade jackcaow/zapcode-releases/zapagent
```

For first installation, replace `upgrade` with `install`. All three commands
are supported: `zapAgent`, `zap`, `zapcode`. Stop active tasks and the VM daemon
before upgrading. User configuration, sessions and writable VM state are kept
outside the package. The separate `zapdev` entry is unchanged.

Verification: 2768 tests passed, 3 environment-dependent skips, no failures;
typecheck and standalone build passed. Real tmux/App coverage includes first-run
setup, choosing later, discovery failure, manual IDs, cancellation, and editing.

This distribution covers macOS Apple Silicon only. The Agent runs on the Host;
process tools run in the bundled VM. No model, API key or user data is included.
Command-line archives are not stapled; first-use ticket verification needs
connectivity. Keep Gatekeeper and quarantine enabled.
