zapAgent 1.14.1 for macOS Apple Silicon includes the new durable follow-up queue,
safe steering, and a freshly rebuilt signed Guest from the same release commit.

- Manage follow-ups with Ctrl+Q: edit, delete, reorder, retry, cancel and steer.
- Guest builds pin every direct/transitive Alpine dependency and verify the
  installed closure. Both architectures are checked before release.
- Fix cancellation arriving before a delegated process launches.
- All three commands remain available: `zapAgent`, `zap`, `zapcode`.

Install or update:

```sh
brew tap JackCaow/zapcode-releases https://github.com/JackCaow/zapcode-releases
brew update
brew upgrade jackcaow/zapcode-releases/zapagent
```

For a first install, use `brew install` instead of `brew upgrade`. Stop active
tasks and the existing profile's VM daemon before upgrading. User configuration,
sessions and writable VM state remain outside the package.

The Agent runs on the Host and process tools run in the bundled VM. This package
contains no model or credentials; configure your provider with `/connect`.
Only macOS Apple Silicon is covered by this distribution.
